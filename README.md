## 📂 Projects

### 🗂️ Project 1 — Cloud Infrastructure Monitor
> **Stack:** AWS (EC2, S3, VPC) · Terraform · Prometheus · Grafana · CloudWatch

- Provisioned a custom VPC, subnets, and S3 bucket using **Terraform** (Infrastructure as Code)
- Deployed a Linux-based backend on **Amazon EC2** in the ap-south-1 region
- Enforced **Principle of Least Privilege** using granular IAM roles and Security Groups
- Set up **Prometheus + Grafana** dashboards to monitor CPU, memory, and disk in real time
- Configured **AWS CloudWatch** alerts for threshold breaches

---

### 🐳 Project 2 — Dockerized App with Full CI/CD Pipeline
> **Stack:** Docker · GitHub Actions · AWS ECR · EC2 · Python Flask

- Built a Python Flask application and packaged it into a **Docker container**
- Automated image builds and pushes to **AWS ECR** on every GitHub commit using **GitHub Actions**
- Deployed to EC2 with a zero-downtime rolling update strategy
- Implemented full **CI/CD pipeline** from code push to live deployment

---

### ☸️ Project 3 — Kubernetes Cluster with SRE Practices
> **Stack:** Kubernetes · Helm · Prometheus · Grafana · Alertmanager

- Deployed the Flask app from Project 2 onto a **Kubernetes cluster** using Helm charts
- Defined **SLOs (Service Level Objectives)** and built runbooks for incident response
- Configured **Alertmanager** for PagerDuty-style alerts on SLO breaches
- Monitored cluster health with Prometheus + Grafana dashboards
